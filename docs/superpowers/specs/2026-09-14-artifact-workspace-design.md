# Artifact Workspace Design

The supplied TCG architecture plan is the accepted design. Implement on the extracted v3.0.13 source and deliver the complete application with a built frontend.

- ArtifactWorkspace replaces FullScreenReviewer and all inline editing/diff components. Cases, scenarios and analysis use one full-screen grid with immutable history, manual editing, and AI proposal decisions. Preserve paired case steps/expected, custom columns, selection, exports and revision checks.
- Keep the existing projection response shape, add artifact_type and mode (read_only/manual/ai_proposal). GET /api/artifacts/{id}/workspace-grid; POST child routes /project, /export and /save. Optional profile binding for types without a profile. Save payload retains expected_revision, optional profile_id/profile_revision/revision/run_id/proposal_id/prompt_id, items, layout and client_request_id; optional report/column_changes preserve existing functionality.
- Use one artifact_proposal storage object with proposal_type=review or revision, artifact_revision, items, report, changes (item diff), status, project/chat/run bindings, dependencies and sources. Normalize old persisted proposal objects once so existing IDs and active prompts remain valid. All new writes use the unified kind.
- The workspace save gateway handles both manual edits and AI resolutions, preserving optimistic concurrency, idempotency, source lineage, native review gate resumption and dependency checks. Remove manual_edits.py and old artifact PUT editing route (or a thin delegate only if required by current clients).
- Remove ItemEditor, TableItemEditor, InlineChangeCard and ChangePreview after replacing every call site; consolidate CSS into workspace.css. Chat displays compact open-workspace cards only for proposals, and model tools direct users to the workspace for confirmation.
- Remove early v6/v7 checkpoint migration/replay. Preserve historical artifacts. Unsupported active legacy runs must give an explicit restart message, never replay or silently execute incompatible state. The upload contains source, not user runtime data, so do not assume the user's checkpoints were inspected.
- Keep existing architecture/dependencies and Chinese UI. No redesign or unrelated feature work. Validate the critical complete workflow and focused invariants; do not expand testing without a concrete integration risk.
