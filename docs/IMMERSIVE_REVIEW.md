# 全屏表格评审 · v3.0.13

保留对话作为入口：生成、提问与进度仍在原对话中。AI 评审卡片和用例成果提供全屏表格入口，离开表格回到原对话。

## 数据与确认契约

- Excel 和评审表格共用后端列投影：同一 Profile、列名、顺序、默认值、步骤编号和自定义字段。
- 原用例与 AI 提案是独立版本；单元格接受、拒绝和人工修改先形成草稿，最后一次性提交。
- 步骤与预期在界面分列，内部仍为成对的步骤数组。编辑时保留配对，不从含歧义的编号文本反推数组。
- 提交校验成果版本、Profile 版本、评审提案和当前确认提示。过期草稿不得覆盖新结果。
- 评审提交通过原 `case_result_review` 确认节点。人工取舍后的内容作为不可变决议保存，后续只应用该决议，避免再次覆盖为 AI 原提案。
- 导出读取当前审阅内容，不构成评审确认。未完成的修改仍标为待处理，不能静默丢弃。
- 侧边助手复用同一会话和 Supervisor，并传递当前成果、版本、选择范围。新建议不静默覆盖本地编辑。
- 有明确字段的意见显示在对应单元格；仅有用例编号的意见显示为行批注；没有对应对象的意见保留在总批注区。

## 实施与验证计划

1. 提取共用 Excel/表格投影，验证两种布局的实际单元格值一致。
2. 增加评审读取、草稿投影、导出和保存接口，验证并发版本保护、幂等和原图确认。
3. 实现全屏表格、差异与批注、人工取舍、成对步骤编辑及侧边对话。
4. 接入原聊天和成果入口；验证局部选择、刷新和返回对话。
5. 运行定向主流程、前端交互、生产构建和发行包启动检查。
