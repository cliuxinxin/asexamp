远程浏览器无法访问本机端口，改用本地浏览器完成。测试环境缺少中文字体，视觉检查临时提供 Noto Sans SC；应用源码和生产静态资源未加入测试字体或测试模型。浏览器截图为检查用临时文件，不包含真实业务数据或真实密钥。

构建有 Mermaid 的大块提示；图表代码按需加载，普通聊天不预载整个图表引擎。npm 环境注入的代理配置警告和 Python 测试依赖弃用警告不影响上述测试。

## 仍需在实际环境验证

- 未调用用户真实模型，未发生远程模型计费；测试验证流程/协议，不能证明具体模型的业务设计质量、速度或大型需求效果。
- 关联覆盖针对已确认的结构化需求和分支，不是测试执行覆盖，也不能证明业务语义没有遗漏。
- 未在 macOS、Windows、Docker 和完全断网环境分别做完整验收；未从零重装整套依赖。
- 60 分钟策略验证的是配置、SDK 参数与受控短期限边界，没有实际等待一小时。

本机升级后可先用小份脱敏需求完成“分析 → 确认业务图 → 生成 → 修改 → 导出”，再核查真实模型的依据和测试方向。
