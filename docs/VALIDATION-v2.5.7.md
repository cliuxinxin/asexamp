# v2.5.7 定向验证

本版只验证用户反馈对应的主流程，没有重跑全部历史回归。

## 覆盖路径

1. HITP 生成进入需求理解确认，再进入场景确认。
2. 在场景确认节点发起 AI 修改；模型调用期间任务保持 `waiting`，公开状态显示 `edit_in_progress=true`。
3. 修改未保存时并发确认返回 HTTP 409，任务不推进，编辑令牌不被清除。
4. 修改保存为场景 Artifact v2 后，任务仍停在场景确认；再次确认可继续生成、评审和总结。
5. 用例生成收到的是修改后的场景标题，不是旧版本。
6. 前端修改期间禁用“确认场景，继续生成用例”，并显示保存提示。

## 边界

定向测试使用本地确定性模型替身，不代表真实内网模型、网络质量或所有历史功能均已验证。前端生产构建用于检查 TypeScript 和打包结果。

## 本地结果

- 后端定向主流程：4 passed（Auto、HITP、并发修改后确认、旧确认流程兼容）。
- 前端定向交互：2 passed（修改期间锁定确认、对话结果修改）。
- `npm run build`：通过（TypeScript 检查和 Vite 生产构建）。
