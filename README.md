# TCG Case Agent 3.0.4

保留原来的红色强调、居中开始页和输入框附近的选项。本版让对话成为主界面：输入框旁显示当前阶段与下一步，成果仅在点击后打开详情，返回时保留对话位置和草稿。业务操作仍统一通过聊天；成果表继续显示需求、场景、用例和步骤 / 预期。

模型失败作为用户发言之后的助手消息保存，并提供问题编号。v3.0.4 将快捷回复放到输入框上方、边框之外，点击直接发送并保留草稿；澄清答复、流程确认和先询问分开显示。澄清问题由后台按实际答案关闭，报告允许附加说明，不再因模型保留旧问题而重复澄清。详见 [澄清与快捷回复复测](docs/CLARIFICATION-v3.0.4.md)。

v3.0.3 增加 Azure OpenAI 环境配置：存在完整 Azure 配置时优先连接 Azure；原网关与 Ollama 继续保留。配置、部署名称、切换规则与验证步骤见 [Azure 连接说明](docs/AZURE-v3.0.3.md)。

- **Chat Agent** 使用 LangChain 原生 Tool Calling，负责询问、估算、修改、资料采用、模板学习、导出和流水线控制。
- **Pipeline Graph** 使用独立 LangGraph 与 SQLite Checkpointer，负责需求理解 → 场景 → 用例 → 评审。状态只保存指针；各阶段从数据库读取产物。
- **Human** 逐一确认理解、场景、用例草稿和评审结果。**Auto** 运行同一流水线，遇到必要澄清或明确暂停要求时停下。
- 确认使用原生 `interrupt()` / `Command(resume=...)`。生成与保存节点和确认节点分离，确认不会再次生成上一阶段。
- 修改保存后仍需确认；回改上游后，确认再更新关联的下一层。估算、解释和总结不推进主流程。
- 项目澄清、Profile 样例、两类模板、Excel、自定义列及人工字段保护保留。覆盖关系直接显示在成果行中。

## 启动

需要 Python 3.11 或更新版本，推荐 Python 3.12。解压到新目录，运行：

```bash
python3 start.py
```

Windows 可使用 `py -3.12 start.py`。首次安装依赖需要联网，包内已有前端构建文件，日常启动不需要 Node.js。

模型地址、名称、认证沿用设置页面或 `.env.example`。**模型与网关必须支持原生 Tool Calling，并转发 `tools`、`tool_choice`、`tool_calls` 和工具结果消息。** 连接测试会实际验证工具调用；只支持普通文本或 JSON 文本的网关不能运行本版代理。

上下文容量仍交给模型服务器决定，没有客户端 Token 容量拒绝。业务批次只在服务器明确超限后拆分，不能安全拆分的条目会说明原因并保留已有成果。聊天超限保留已完成工具操作，不重放整个回合。输出预算在模型设置中独立配置。

## 升级与数据

停止旧服务并备份原数据目录，用新版代码指向该目录启动：

```bash
python3 start.py --data-dir /path/to/existing/data
```

项目、资料、Profile、成果版本和历史消息保留。能可靠定位的旧人工确认点迁移为原生检查点；正在执行或位置不明确的旧任务保留成果并提示重新开始，不猜测确认或重放旧引擎。旧版代码与备份数据应一并保留，回退时使用升级前备份。

同项目共享需要访问同一后端服务。启动器支持 `--host` 与 `--allowed-hosts`；本版没有新增账号和成员权限系统。

## 验证与限制

定向测试使用真实 HTTP、SQLite、LangChain Tool Calling 消息及 LangGraph 检查点，控制模型返回来验证流程、并发和数据行为。尚未连接你的内网模型；演示前请完成连接测试，并按演示脚本预跑一次。

本轮包含前端交互测试、TypeScript 和生产构建验证。浏览器访问被环境策略阻止，尚未完成真实页面视觉验收。

`tests/` 是当前原生架构测试；`legacy-tests/` 保存被替代架构的历史测试，默认不执行，本轮未执行全量历史测试。快捷回复以 v3.0.4 说明为准，连接与排查见 v3.0.3 Azure 说明和 v3.0.2 日志说明，后端沿用原生双核架构。
