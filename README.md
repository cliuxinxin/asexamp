# TCG Case Agent 2.4.0

本地测试用例生成助手。本版修复 v2.3 简化调用时跳过业务流程及人工确认的问题，恢复完整流程，并参照 execution-agent-UI 的生成页布局扩大聊天区域。

## 启动

需要 Python 3.11+，推荐 3.12。已包含前端构建产物，正常使用不需要 Node.js。

1. 解压到新目录，复制 `.env.example` 为 `.env`，填写模型地址、名称和 Key。
2. 运行 `python3 start.py`；Windows 可用 `py -3.12 start.py`。首次安装依赖需要联网。
3. 打开 http://127.0.0.1:8000 ，上传需求或粘贴正文，选择任务和 MODE 后发送。

私有网关继续使用原有 `POST /api/v1/chat/completions` 及默认 `X-API-Key`；默认请求仅 model/messages，不依赖 tools 或 embedding 接口。

## 生成流程

需求理解与业务图 → 澄清或记录假设 → 测试场景 → 测试用例 → 一轮 AI 审核与定向修订 → 保存与导出。

- **Auto**：自动经过上述阶段，不等待人工；歧义记录为待核实风险。中间产物保存在后台，聊天展示最终结果。
- **HITP · 人工关键节点**：存在关键问题时先澄清；然后展示需求理解、业务图和深度建议，等待确认；生成场景后再次等待确认，使用最新修改的场景生成用例。
- 理解确认时可编辑规则、摘要和 Mermaid 图源码，或让 AI 修改此结果；场景也可表单编辑或对话修改。
- Profile 的场景颗粒度与用例深度独立设置；确认时可按需要统一覆盖本轮深度。
- 支持分析需求、生成场景、生成用例、评审用例、提问、学习模板；自动识别意图可能增加一次路由请求。

普通生成通常包括四次核心模型调用，每次负责不同业务阶段，**这些阶段不是文档分批**。用户澄清、格式修复、输出续写可能增加请求。只有完整阶段上下文超过配置预算时才按条目分组。单个条目加必要上下文仍超限时明确报错，不静默截断；超大文档跨组语义质量仍需人工复核。

## 界面与模板

默认宽聊天区域，生成结果直接显示在对话中。顶部可主动打开并排结果面板并调整宽度；小屏幕收起导航。

顶部“Profile 与 Excel 模板”可修改语言、规则、场景与用例深度、Excel 行布局、Sheet 名、文件名、列映射和顺序。可更新当前 Profile、另存新 Profile，或仅下一次运行使用。

学习上传的 Excel：选择“学习模板”，上传示例文件，再发送学习要求；AI 返回建议后由用户选择保存方式。模板学习提取结构和写作规则，不保证保留原文件的复杂合并单元格、宏或视觉样式。导出时可使用生成时配置或当前项目的其他 Profile。文件名支持 `{project}` 和 `{date}`。

## 容量与数据

```dotenv
TCG_MODEL_CONTEXT_TOKENS=32768
TCG_OUTPUT_TOKENS=8192
TCG_SEND_OUTPUT_LIMIT=false
```

配置必须符合实际模型能力。预算使用保守估算而非精确 tokenizer。私有网关只有明确支持 max_tokens 时才启用发送输出限制；Ollama 使用 num_ctx/num_predict。

新任务采用 graph_version=6；保留旧 graph 4/5 执行路径。请用新会话验证新流程，旧的进行中任务不会自动迁移。默认数据目录 `data/`。

```bash
python3 start.py --port 8080 --no-browser
python3 start.py --data-dir ./data-v24 --env-file ./.env
python3 start.py --no-install --no-browser
```

本项目是本机测试原型，不是已实现整份 PRD 的企业平台；企业权限、OKTA、远程知识库等不在本次交付范围。用例生成和 AI 审核不代表实际执行测试成功。
